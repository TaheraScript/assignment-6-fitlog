1)  My project name : assignment-6-fitLog

2) Short description about project : 
                                                       FitLog is a workout library and daily planning app built with Next.js. It helps users explore different exercises, view detailed workout information, and create a simple daily workout plan. Users can also save workouts for later and keep track of their selected exercises.

3)  Those technologies are  used in my project : 

 Next.js (App Router)
 TypeScript
 Tailwind CSS
 DaisyUI
 React Toastify
 React Icons

 4)  5 key features of the project are given below: 

 Workout Library

Browse a collection of workouts displayed in a responsive card-based layout. The layout automatically adjusts for mobile, tablet, and desktop screens.

Detailed Workout Information

Each workout has its own detail page with an image, description, sets, reps, duration, calories, and step-by-step instructions.

Create Your Daily Plan

Users can add workouts to their daily plan and build a personalized routine. The plan allows a maximum of five workouts per day to keep it simple and manageable.

Save Workouts for Later

Users can save their favorite workouts and access them anytime from the **My Plan** section. Workout data is stored in `localStorage`, so it remains available even after refreshing the page.

Search, Sort & Responsive UI

The My Plan page includes search and sorting options for quickly finding workouts by duration, calories, or rating. The entire application is designed to work smoothly across different screen sizes.
